# Skull Kid — Android

An unofficial Android port of the 2002 Flash game **the skullkid**, with controller and touchscreen support.

Tested on **AYN Odin 2 Portal**. Requires **Android 8.0 or newer**.

## Features

- Gamepad controls with a remappable USE action.
- Touchscreen joystick or D-pad with adjustable controls.
- Original display proportions or stretch to fill the screen.
- FrostFrontend settings for Graphics, Sound, Controls, Touch Settings and Updates.
- Custom launcher icon and persistent settings.

## Installation

1. Install the Android APK from [Releases](https://github.com/Frostie77/Skull-Kid/releases).
2. Download the [original Skull Kid SWF](https://uploads.ungrounded.net/63000/63747_skullkid.swf).
3. Open the app, choose **Select SWF File**, and import it.

The app remembers your imported game file. The original Flash game is downloaded separately and is not included in the APK.

## Controls

- **Left stick / D-pad:** move; duck and stand during gunfights.
- **A / USE:** chainsaw or shoot.
- **Start / menu icon:** open FrostFrontend.

## Updates

Check for updates through **FrostFrontend → Updates**, or enable automatic checks. Updates open the verified GitHub release page.

Install newer public APKs over the existing public version to preserve your imported game and settings.
